# Triage Labels

| 스킬의 역할 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 검토 필요 |
| `needs-info` | `needs-info` | 추가 정보 대기 |
| `ready-for-agent` | `ready-for-agent` | 에이전트 작업 가능 |
| `ready-for-human` | `ready-for-human` | 사람의 작업 필요 |
| `wontfix` | `wontfix` | 진행하지 않음 |

스킬이 triage 역할을 언급하면 대응하는 GitHub 라벨을 사용한다.
