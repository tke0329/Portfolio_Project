# Design reference

The desktop and mobile boards supplied with the PRD are stored at:

- `docs/reference/desktop-mockup.png`
- `docs/reference/mobile-mockup.png`

They guide layout, color, navigation, panel treatment, and responsive composition. Text and project data shown inside the boards are examples. Actual content comes from verified profile data.

## Production art

The following original assets were generated for this project with the built-in image generation tool and saved as optimized WebP files:

| File | Use | Prompt direction |
| --- | --- | --- |
| `public/images/hero-workshop.webp` | Home background | Wide 16-bit fantasy scholar workshop at night, dark navy wall with left-side text space, arched window showing castle town, warm lanterns, desk, no characters or UI. |
| `public/images/npc-developer.webp` | NPC character | Transparent 16-bit pixel art welcoming adult fantasy developer NPC, indigo hair, navy wizard hat and cloak, antique gold accents, no text or UI. |
| `public/images/castle-town.webp` | Project card art | 16-bit pixel art castle town at blue hour, glowing windows, rooftops and lanterns, navy and antique gold palette, no text or UI. |
| `public/images/magic-workshop.webp` | Project card art | 16-bit pixel art magical workshop in a medieval tower with books, rune circle, brass machinery and crystal lamps, navy and gold palette, no text or UI. |

The card art is decorative and does not depict a project's actual implementation or architecture.
