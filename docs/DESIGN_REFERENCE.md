# Design reference

The desktop and mobile boards supplied with the PRD are stored at:

- `docs/reference/desktop-mockup.png`
- `docs/reference/mobile-mockup.png`

They guide layout, color, navigation, panel treatment, and responsive composition. Text and project data shown inside the boards are examples. Actual content comes from verified profile data.

## Home NPC motion

The user supplied a short pixel-character animation as the idle-motion reference. The home character plays a 22-frame loop over 3.6 seconds: the chest expands and relaxes, hair and cloak follow with a slight delay, and the eyes blink once. All frames derive from one aligned pose, so the character identity does not flicker and the boots stay planted. The opening workshop hero retains the character and headline; the wooden noticeboard appears on scroll. Hovering or focusing the character holds the greeting frame, while hovering or focusing the guide button holds the guiding frame. Only clicking the character opens the AI chat panel; the guide button opens the navigation dialogue. Reduced-motion settings use the static idle pose.

The earlier `hero-wizard-breathing.webp` three-frame experiment is retained for comparison but is no longer used on the site.
